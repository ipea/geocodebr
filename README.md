# geocodebr

Geolocalização de endereços brasileiros em massa, sem limite de consultas, a partir de dados abertos —
baseado no CNEFE (Cadastro Nacional de Endereços para Fins Estatísticos, publicado pelo IBGE).

Este repositório é um monorepo, organizado por linguagem:

- **[`r-package/`](r-package/)** — o pacote R **{geocodebr}**, publicado no CRAN. Veja o
  [README completo](r-package/README.md) para instalação, exemplos e documentação.
- **`python-package/`** — porte para Python, ainda não iniciado.
